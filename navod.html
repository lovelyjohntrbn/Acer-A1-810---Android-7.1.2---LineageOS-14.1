Restore on the tested tablet

No public universal installation package is available yet. This guide describes restoring a private backup to the same tablet. The backup has not been tested by flashing it back.

What you will need

  • An Acer Iconia A1-810, a reliable USB cable, Windows, a working MediaTek VCOM driver, and SP Flash Tool.
  • Your own backup of the original firmware and device-specific data, plus a verified recovery procedure.
  • A matching scatter file and boot.img and system.img images. Verify their SHA-256 hashes and the tablet’s partition layout before use.

The private raw backup of boot and system does not include the full /data partition, personal accounts, downloaded games, game data, or updates stored there. The recovery image is a separate backup.

Using SP Flash Tool

  1. Load the scatter file for the specific tablet and uncheck every row.
  2. Select only BOOTIMG with boot.img and ANDROID with system.img. Confirm that no other rows are selected.
  3. Use Download Only, start Download, and connect the powered-off tablet using the procedure for your driver. Do not disconnect it during writing.
  4. When the tool confirms completion, disconnect and start the tablet. The first boot may take longer; the green confirmation does not by itself prove that Android will boot.

Do not use Format or Firmware Upgrade. Do not select preloader, NVRAM, PROTECT, MBR, or EBR. Never transfer device-specific NVRAM backups between devices.

What has been tested

On one tablet, hardware graphics acceleration, Wi-Fi, Bluetooth, speaker, microphone, screen rotation, and the Play Store worked. The camera does not work yet and VPN has not been tested. Google sign-in can temporarily slow the tablet while synchronization and updates complete.

Google services are included in the tested private system snapshot. This does not grant permission to distribute them publicly. Instructions for separate installation will follow only after an appropriate package and recovery procedure are verified.
